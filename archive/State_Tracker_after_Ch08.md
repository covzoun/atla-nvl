# State_Tracker.md

## Purpose and Update Rules

This is the project's **single living continuity document**. It tracks both **story state** (injuries, inventory, location, objectives, timeline, unresolved threads) and **relationship state** (trust, tension, progression, active secrets). There is no separate relationship tracker.

- Updated by the Phase 3 Continuity Clerk after each completed chapter, then verified by the human at Gate 3.
- It must never rewrite locked canon or chronology (`Canon.md`, `Story_Bible.md`, `Relationships.md` remain authoritative). It records only changes explicitly supported by the completed chapter.
- **STATE sections** (Current Story Position, Jake's Current State, Zuko's Current State, Relationship States) are **replaced** to reflect the new current state. No history is appended here.
- **LOG sections** (Unresolved Threads, Character Introductions Log, Recent Events Summary) are **appended and pruned**: threads are added when opened and marked `Resolved` (not deleted) when closed; the Recent Events Summary holds only the last 1-2 chapters, dropping older entries as new ones are added.
- Unchanged sections are preserved verbatim.
