## Rules

1. **1 Canon Episode = 1 Chapter.** There are no merged episodes.
2. **Original Content chapters** use the macro map B-plot entry as their structural anchor: the blueprint's Canon Anchor becomes a Macro Map B-Plot Anchor, and the Cleaned Canon Reference is marked "N/A — original chapter."
3. Phase 3 snapshots and file naming use these chapter numbers (`Chapter_04.md`, `State_Tracker_after_Ch04.md`, etc.).
